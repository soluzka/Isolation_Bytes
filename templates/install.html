Install on iOS / iPadOS

  1. Tap the Share button (square with up arrow) in Safari's toolbar
  2. Scroll down and tap Add to Home Screen
  3. Tap Add
  4. Isolation Bytes will appear on your home screen with its own icon

It works like a native app — fullscreen, offline cache, and push notifications.

Install via Configuration Profile

Downloads a profile that adds Isolation Bytes to your home screen automatically. Open Settings > Profile Downloaded to install.

Startup Apps: iOS does not allow third-party apps to auto-launch at boot. Pin Isolation Bytes to your home screen or Dock for one-tap access, and enable notifications for security alerts.
